# 実装と検証

## 構図・表示の確認

`concept.png` と、1536 × 1024の本番ビルドのブラウザ画像を比較しました。

| 項目 | 方向性 | 実装・確認 |
| --- | --- | --- |
| 世界 | 雲海、浮島、木造の温泉街 | 4つの歩ける浮島と遠景の浮島を3Dで描画 |
| 構図 | 街、朱塗りの橋、右側の露天風呂 | 初期視点から主要な街と温泉島が見えるよう調整 |
| 建物 | 濃い青緑の瓦、暖色の障子 | 多層屋根、瓦筋、格子、欄干、提灯、縦書き看板を立体化 |
| 書体 | 明朝体と控えめなUI | Noto Serif JP / Noto Sans JP、淡い金色の文字 |
| 画面構成 | 左上ロゴ、左下現在地、右下地図 | StyleXで実装し、枠線のコンパイル不備を修正 |
| モバイル | 風景を中心とした画面 | 390 × 844で操作パネルの重なりと横方向のはみ出しを確認 |
| 動き | 湯けむり、水面、散策 | 水面シェーダー、蒸気、花びら、歩行・ジャンプを実装 |

コンセプトの細密な描き込みに対して、実装の建物・地形はポリゴンの形を見せるスタイルです。
コンセプト画像と同じ写実的な質感ではありません。
UIの所在地表示は、固定された温泉名ではなく実際の現在地に追従します。

## 自動検証

- TypeScriptチェックと本番ビルド: 成功
- ESLint: 成功
- Prettier: 成功
- 地形・橋の高さの連続性、発見地点、衝突判定のユニットテスト: 3件成功
- デスクトップ操作と保存機能のE2Eテスト: 成功
- モバイルの表示・方向ボタン・ダイアログのE2Eテスト: 成功
- 3本の橋を歩き、全4地点を記録するE2Eテスト: 成功

本番ビルドでもデスクトップ・モバイルの操作テストを実行しました。
デスクトップのテストでは、位置変化、手帖の永続化、ダイアログ中の一時停止、音声切り替え、夜景切り替え、PNGダウンロード、UI非表示、操作ガイド、ブラウザのJavaScriptエラーを確認しています。

## 公開

Cloudflare上に既存の `yukagecho` が存在したため、このプロジェクトは新しい `yukagecho-anime` Workerとして公開しました。
ビルド成果物と背景画像を配信し、実装ソース・テスト・設計画像は配信対象に含めません。

公開URLでも、デスクトップとモバイルのE2Eテスト2件が成功しました。
